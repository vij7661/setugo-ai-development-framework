2. The governance-history runtime-read detector can be bypassed. path_class classifies any expression containing schemas/governance-r8 as SCHEMA before checking for history, and it does not normalize or resolve paths. A path such as schemas/governance-r8/v15-r1/../../../governance-r8/... or an inherited SCHEMA base with ../../../governance-r8/... can be classified as permitted schema access while actually escaping to governance-history root. The detector also only checks open, read_text, and read_bytes, so directory/glob reads such as os.listdir, os.scandir, glob, Path.glob, Path.rglob, or Path.iterdir are not covered. This can permit prohibited runtime governance-history dependencies.
