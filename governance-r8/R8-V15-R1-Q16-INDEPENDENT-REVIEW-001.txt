H. API_AND_REVIEWER_DELIVERY_ASSESSMENT
- Actual Gemini wire-request preservation: The real `invoke` now derives URL, method, payload, and timeout from the canonical semantic projection, which closes the prior parallel-unused-helper concern for those fields. Retry behavior is still not derived from or checked against the projection; `wire["retry_policy"]` is ignored. Therefore execution behavior preservation is incomplete for retry semantics (H-01). `retry_policy` is also not recursively scanned for forbidden/secret keys (M-01).
- Authentication secrets: The real Gemini semantic projection excludes authentication by construction, and the API key is added only to transport headers. The generic provider contract recursively rejects secret-like structured keys in `provider_parameters` and structured message fields, but not in `retry_policy` (M-01), and manifest secret values are not scanned (L-01).
- Reviewer delivery modes: `URL_ONLY` remains non-promotable. `PLATFORM_MATERIALIZED_CONTENT` is the only mode accepted by the v2 real path and is wired before provider invocation. `PROVIDER_URL_CONTEXT` now requires content SHA-256 and byte count, but its URL is not bound to the expected source object (M-04). `AUTHENTICATED_GITHUB_MCP_READ_ONLY` requires read-only tool access and an object ID, but the object ID is not compared to an expected repository object (M-04). Manifest truthfulness fields are not fully enforced (M-02), and the admitted manifest is not persisted in output evidence (M-03).
- Real review path integration: `platform_candidate_review_v2` requires an access manifest and calls delivery validation before provider invocation. The workflow passes `--access-manifest`. The committed invariant workflow runs the Q16-specific integration tests. However, the Q15 review/merge gate itself is not wired into a real workflow, only unit-tested (M-05).
- Q15 review/merge gate: It binds parsed candidate identity to expected identity, both execution statements, and the v2 attestation. It does not bind the exact review artifact hash (H-03), and the v2 attestation lacks an external run/job trust anchor (H-02).
