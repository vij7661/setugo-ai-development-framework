12. **Over-constraint / liveness**
    - schema must not reject a case the frozen design explicitly permits;
    - nullable/conditional fields must not make lawful recovery/effects/rotation impossible;
    - fail-closed rules must not be replaced by weaker fallback for liveness.

- more than one unique final digest -> SEMANTIC_ENTRY_CONFLICT;

No authority-bearing mutable state may have two independent owners.

## 4. Cross-rule precedence matrix

| Conflict shape | Winning rule | Result |
|---|---|---|
| High AIM specificity vs lower active descriptor + invalid high ANY permission | high-specificity blocker | AIM_SCOPE_PERMISSION_REEVALUATION_REQUIRED |
| High semantic specificity vs lower active rule + revoked high rule | revoked high blocker | SEMANTIC_SCOPE_REVOKED unless valid discharge |
| Valid successor vs unrelated active peer | discharge revoked first, then SREP compare | unique result or conflict |
| Policy says implementation valid but RIR lacks exact tuple | RIR authorization | RESOLVER_IMPLEMENTATION_UNBOUND |
| RIR ACTIVE label but sequence not effective | temporal predicate | ineligible |
| Conformance PASS but evidence stale | RCS freshness | unqualified |
| Scope replacement says broader but no expansion authority | SRTT | invalid |
| Old review packet says PASS but current state changed | current seal/state | no authority |
| Legacy guard table conflicts with GuardRegistry | GuardRegistry | legacy table ignored as authority |
| Liveness need conflicts with trust proof unavailable | fail-closed rule | blocked; no weaker fallback |

## 5. Matrix consistency checks

Internal NCG checks required:
- every stage output consumed only by later stages;
- no cycle in authority-dependency edges except explicitly stateful commit loops;
- no blocker can be converted to eligible state by a later stage without a governed successor/recovery event;
- every mutable authority state has exactly one owner;
- every owner has an explicit head/digest or external trust root;
- review-only artifacts cannot directly mutate runtime authority.


## 4. R8 v15 direct-dependency graph contract

The structured dependency graph represents **direct authority-relevant consumption/precondition edges**, not transitive closure.

Rules:
- an edge A -> B exists only when B directly consumes A's current authority state/output or cannot be evaluated without A's current qualified state;
- transitive reachability is not duplicated as a direct edge;
- graph edges are generated from this matrix, not manually inserted because a reviewer suggested them;
- any direct dependency declared here but absent from the generated graph is NCG failure;
- any generated edge with no matrix declaration is NCG failure.

Reviewer-suggested edges from the v14 review are dispositioned as follows:
- `Revocation -> RIR2`: not added merely because RIR records contain a retirement/revocation sequence; that lifecycle predicate is read from the current RIR record. Add only if a future normalized rule makes RIR2 directly consume the global revocation stream.
- `CSM5 -> RCS2`: current dependency is mediated by ResolverPolicy/RIR2. No duplicate transitive edge is added.
- `GuardRegistry -> CSRULE_SRTT_SREP`: not a runtime semantic-resolution dependency. GuardRegistry governs qualification/review proof and must not silently become runtime authority.

## 5. R8 v15 closure-specific interaction rules

- Multi-revoked composition follows CSRULE-6: no partial discharge enters final selection.
- SRTT-4 uses a fixed REVOKED source domain plus the frozen SRTT-4 RuleRegistry.
- `old_scope_effect=REPLACE_OLD_SCOPE_FOR_MAPPED_MATCH` may terminate at `EXACT_MATCH`; destination match type does not derive the effect label.
- semantic_state_sequence is current LAS-derived state and cannot be caller-selected or rolled back.
- rotation barriers do not manufacture or reinterpret external-effect success.
- transient time/conformance/revocation freshness outage remains fail-closed until a same-or-stronger qualified dependency path is restored.
