# Failure Triage Skill

This directory is reserved for the native Claude-generated `SKILL.md` used in the Setugo multi-LLM development experiment.

The skill's purpose is to force diagnosis before corrective action when a test, build, implementation, or CI failure occurs.

Expected root-cause categories:

- `CODE DEFECT`
- `FIXTURE-DATA DEFECT`
- `TEST DEFECT`
- `ENVIRONMENT-TOOLING DEFECT`
- `REQUIREMENT UNRESOLVED`

The original native file should be published here without converting it into a PDF and without presenting reconstructed text as the original. The canonical `SKILL.md` will be added only from the verified source artifact.
