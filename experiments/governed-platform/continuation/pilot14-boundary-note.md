# EXP-I Pilot 14 boundary note

Pilot 14 remains a same-host bounded prototype. It tests externally governed root-key eligibility and rotation semantics, not independent administrative trust domains, HSM/KMS nonextractability, threshold root authority, or production PKI. EXP-O Pilot 27 remains separately blocked pending distinct cloud/admin trust domains and must not be simulated away inside Pilot 14.
